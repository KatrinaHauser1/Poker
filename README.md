# Poker

Poker Seven-Card Stud Hand Analyzer
to compile:

Java:
javac poker.java cards.java ratings.java
java poker

OR with input file:

file handsets/{fileName}
javac poker.java cards.java ratings.java
java poker handsets/{fileName}

C#:

- mcs poker.cs cards.cs ratings.cs
- mono poker.exe

OR with input file:

- file handsets/{fileName} 
- mcs poker.cs cards.cs ratings.cs
- mono poker.exe handsets/{fileName}
  
have fun!
